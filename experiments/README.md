# Preserved experiments

These copies are outside the unified app and deployment dependencies:

- `model_chat.py`: single-turn Ollama client for local `qwen3.5:0.8b`.
- `memory.py`: conversational Ollama gym-trainer experiment.
- `labeler.html`: browser satellite CSV labeling tool.
- `yolov8n.pt`: general object detector, not the custom gesture model.

Nothing is declared obsolete or deleted. Original root copies remain intact. Ollama experiments require an Ollama server on localhost:11434 and their own dependencies; the deployed training lab does not install Ollama.
